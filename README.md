## Overview

Blue Cat Late Replies is a powerful multi-tap delay plugin that hosts VST/AU plugins on each tap, enabling complex serial or parallel effect chains per delay repeat.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Blue Cat Late Replies** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Multi-Tap** | Up to 8 delay taps with independent time, level, pan, and filter |
| **Plugin Hosting** | Load any VST/AU plugin on each tap for processed echoes |
| **Groove Lock** | Tempo-synced taps with swing and groove quantization |
| **Reverb Mode** | High tap density mode for algorithmic reverb-like textures |
